# vaar

**VAAR — o VAR da sua quadra.** Repositório **público** com o site público do VAAR.

> **Em linguagem simples:** o VAAR grava as quadras esportivas sem parar. Depois de uma jogada bonita,
> o jogador aperta um botão e recebe o clipe do lance pelo WhatsApp. Este repositório vai guardar
> **apenas o site que qualquer pessoa pode ver**. Tudo o que é interno fica num repositório privado.

## O que tem aqui

| Onde | O que tem |
| --- | --- |
| [`CLAUDE.md`](CLAUDE.md) | as regras de como trabalhamos neste repositório |
| [`docs/hospedagem.md`](docs/hospedagem.md) | onde o site vai ficar no ar e o risco do GitHub Pages |
| `.github/pull_request_template.md` | o modelo que todo pull request segue |

O site em si ainda não existe: ele chega depois do esqueleto do produto.

## Como uma mudança entra

Toda mudança chega como um **pull request (PR)** em português. Um revisor confere e o dono faz o Merge.
Ninguém grava direto na `main`.
